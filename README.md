# 🦦 제 1회 먼작귀 전국 랏코 박사 모의고사 (Rakko Quiz)

먼작귀(치이카와) 공식 원작 만화/애니메이션/극장판 설정을 바탕으로 제작된 **랏코 박사력 인증 테스트 웹사이트**입니다.

---

## 🌟 주요 특징

1. **공식 에피소드 기반 12문항 고품질 퀴즈**
   - 종족(해달 vs 수달 쿠리만쥬)
   - 토벌 랭킹 1위 & 바이킹 소드 각인 특권
   - 치이카와/하치와레의 "선생님" 호칭 사연
   - 갭 모에: 딸기 파르페 사랑 & 쓴 커피 못 마심
   - 치명적 약점: 극심한 음치/박치(우사기 꽈배기 귀 사건) & 냉탕 참기
   - 차덕후 면모 & 기념공원 군 동상
   - 나가노 작가 공인 외모 TMI (코 크기)
   - 상극인 모몽가와의 관계 등
2. **먼작귀 감성의 포근한 UI & 랏코 공식 일러스트 탑재**
   - 랏코 공식 일러스트 탑재 및 둥실둥실 애니메이션
   - 랏코의 시그니처 컬러(버건디 망토, 골드 랭커 뱃지, 딸기 파르페 핑크)
   - 깔끔한 수험지/성적표 카드 레이아웃
3. **상세한 결과 리포트 & 오답노트**
   - 100점 만점 채점 및 점수별 랏코 칭호/명대사 코멘트
   - 전 문항 공식 설정 기반 상세 해설 & 오답노트
4. **결과 링크 공유 지원**

---

## 💻 실행 방법

- `index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 실행합니다.

## 🚀 GitHub Pages 배포 방법

1. GitHub에 새 저장소(`rakko-test`)를 만듭니다.
2. 이 폴더의 파일들(`index.html`, `style.css`, `script.js`, `README.md`)을 업로드합니다.
3. 저장소의 **Settings** ➔ **Pages** 에서 Branch를 `main`으로 설정하고 **Save**를 누르면 끝!
