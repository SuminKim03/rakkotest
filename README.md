# 🦦 랏코 키우기

토벌 랭킹 1위 참스승님 랏코를 직접 쓰다듬고, 간식 주고, 토벌 보내며 키우는 웹 미니게임입니다.

---

## 🎮 플레이 방법

- **입장**: 비밀번호만 입력하면 그게 곧 계정이에요. 처음 보는 비밀번호면 "새 랏코 맞이하기"로 새로 시작합니다.
  - 저장은 브라우저(localStorage)에 비밀번호 해시별로 됩니다. 다른 기기·브라우저와는 공유되지 않아요.
- **만지기**
  - 톡 찌르기: 표정이 바뀌고 한마디 (너무 많이 찌르면 삐짐)
  - 꾹 누른 채 문지르기: 쓰다듬기 게이지가 차면 하트 + 기분↑ + 조개
- **상태**: 배부름 · 기분 · 기력은 실제 시간에 따라 변해요 (자리 비운 시간도 최대 8시간까지 반영)
- **돌보기**
  - ⚔️ 토벌 보내기 (10초): 기력 -25, 조개 획득 — 기분이 좋을수록 성공률↑
  - 💤 낮잠 재우기 (20초): 기력 +40
  - 📅 출석 도장: 하루 1번 조개 +50
  - 💬 말 걸기
- **재화 🐚 조개**: 토벌 · 쓰다듬기(하루 40개까지) · 출석 · 모의고사 · 친밀도 레벨업으로 획득
- **상점**: 간식(가방에 보관 후 먹이기), 옷(옷장으로), 방 배경(구매 즉시 적용)
- **옷장**: 머리·얼굴 두 칸에 옷을 입혀요. 표정이 바뀌어도 옷이 머리·눈 위치를 따라갑니다.
  - 머리: 딸기 리본, 꽃 화관, 밀짚모자, 산타 모자, 바이킹 투구, 파르페 모자, 랭커 왕관
  - 얼굴: 동그란 안경, 선글라스, 하트 볼스티커
- **미니 컨텐츠 · 제 1회 전국 랏코 박사 모의고사**: 돌보기 탭에서 입장. 12문항, 정답당 🐚3, 만점 보너스 🐚20 (보상은 하루 3회까지, 연습은 무제한). 결과 화면에 오답 노트와 해설이 나와요.
- **친밀도 레벨**: 처음 만난 사이 → 얼굴 아는 먼작귀 → 인사하는 사이 → 견습 제자 → 정식 제자 → 수석 제자 → 평생의 애제자

## 🖼 이미지

- 원본: `rakkopng/*.png`
- 웹용 경량 버전: `rakkopng/web/*.webp` (게임에서 사용)
- 옷 위치는 `script.js`의 `ANCHORS`(표정별 머리·눈 위치)와 각 옷의 `place` 값으로 조정해요.
- 표정은 상태·행동에 따라 자동으로 바뀝니다 (배고픔 → expact, 졸림 → yawn, 토벌 → resolution, 쓰다듬기 → nod 등)

## 💻 실행 / 배포

- `index.html` 을 브라우저로 열면 바로 실행됩니다.
- GitHub Pages: 저장소 **Settings → Pages** 에서 Branch를 `main` 으로 설정하면 배포됩니다.
