# 🦦 랏코 키우기

토벌 랭킹 1위 참스승님 랏코를 직접 쓰다듬고, 간식 주고, 토벌 보내며 키우는 웹 미니게임입니다.

---

## 🎮 플레이 방법

- **입장**: 비밀번호만 입력하면 그게 곧 계정이에요. 처음 보는 비밀번호면 "새 랏코 맞이하기"로 새로 시작합니다.
  - `firebase-config.js`를 채우면 **서버 저장**: 같은 비밀번호면 어느 기기·누구든 같은 랏코를 보고, 다른 화면에서 바뀐 것도 실시간 반영돼요.
  - 비워두면 이 브라우저(localStorage)에만 저장돼요.
  - 비밀번호 원문은 저장하지 않고 해시(16자리)를 문서 이름으로 써요. 장난감 수준 보안이니 실제로 쓰는 비밀번호는 넣지 마세요.
- **만지기**
  - 톡 찌르기: 표정이 바뀌고 한마디 (너무 많이 찌르면 삐짐)
  - 꾹 누른 채 문지르기: 쓰다듬기 게이지가 차면 하트 + 기분↑ + 조개
- **상태**: 배부름 · 기분 · 기력은 실제 시간에 따라 변해요 (자리 비운 시간도 최대 8시간까지 반영)
  - 기분이 깎이는 경우: 시간(분당 -0.6 = 시간당 약 -36, 배부름 20 미만이면 2배, 기력 15 미만이면 1.5배 더), 5초 안에 7번 이상 찌르기(-5), 토벌 실패(-12), 드라이브 중 충돌(1번당 -6)
- **돌보기**
  - ⚔️ 토벌 보내기: 타이밍 베기 미니게임 (아래 참고)
  - 💤 낮잠 재우기 (1분): 기력 +30, 깨고 나서 10분 쿨타임
  - 📅 출석 도장: 하루 1번, 연속 출석할수록 🐚 25 → 최대 55
  - 🚗 드라이브: 방향키 미니게임, 끝나면 기력 +5~10 랜덤 (3분마다 1번)
  - 💬 말 걸기
- **토벌 미니게임**: 상대를 고르고, 좌우로 움직이는 바늘이 구간 안에 있을 때 베기 (버튼 / 화면 탭 / 스페이스바)
  - 금색 구간 = 회심(2배 데미지), 연한 구간 = 베기, 밖 = 빗나감(하트 -1, 3번 빗나가면 실패)
  - 기분이 좋을수록 판정 구간이 넓어지고, 맞힐수록 바늘이 빨라져요
  - 괴물 머리 위 주황 막대(반격 타이머)가 다 줄면 반격당해 하트 -1 — 망설이면 안 돼요
  - 꼬마 덩어리(HP4, 기력 15, 🐚5~7) / 수풀 괴물(HP6, 판정 구간이 천천히 움직임, 기력 25, 🐚10~13) / 거대 괴수(HP9, 구간이 빠르게 움직임, Lv.3부터, 기력 35, 🐚18~22)
  - 회심 1번당 🐚+1, 노데미지 승리 🐚+2, 가끔 간식 전리품. 하루 8번 넘게 토벌하면 보상 절반
- **드라이브 미니게임**: ↑↓(W S) 차선 바꾸기, ←→(A D) 느리게/빠르게 (모바일은 화면 버튼, 캔버스 위/아래 탭도 가능)
  - 흙탕물 웅덩이를 지나가면 첨벙! 기분 +1 (최대 +10), 라바콘·돌에 부딪히면 하트 -1 · 기분 -6
  - 시간이 갈수록 빨라지고, 장애물이 두 차선을 동시에 막기도 해요 (항상 한 차선은 비어 있음)
  - 45초 달리거나 하트 3개를 다 잃으면 끝. 어떻게 끝나든 기력 +5~10
- **재화 🐚 조개** (하루 적당히 놀면 100~150개 정도 모이도록 조정)
  - 수입: 토벌, 출석, 쓰다듬기(1개, 하루 10개까지), 모의고사(하루 1회), 친밀도 레벨업
  - 지출: 간식 8~60, 옷 60~500, 배경 250~650
- **상점**: 간식(가방에 보관 후 먹이기 — 음식마다 기력도 조금씩: 조개 구이 +3, 커스터드 푸딩 +4, 단팥 붕어빵 +5, 딸기 파르페 +8, 커피는 +25), 옷(옷장으로), 방 배경(구매 즉시 적용)
- **옷장**: 머리·얼굴 두 칸에 옷을 입혀요. 표정이 바뀌어도 옷이 머리·눈 위치를 따라갑니다.
  - 머리: 딸기 리본, 꽃 화관, 밀짚모자, 산타 모자, 바이킹 투구, 파르페 모자, 랭커 왕관
  - 얼굴: 동그란 안경, 선글라스, 하트 볼스티커
- **미니 컨텐츠 · 제 1회 전국 랏코 박사 모의고사**: 돌보기 탭에서 입장. 12문항, 정답당 🐚2, 만점 보너스 🐚10 (보상은 하루 1회, 연습은 무제한). 결과 화면에 오답 노트와 해설이 나와요.
- **친밀도 레벨**: 처음 만난 사이 → 얼굴 아는 먼작귀 → 인사하는 사이 → 견습 제자 → 정식 제자 → 수석 제자 → 평생의 애제자

## 🖼 이미지

- 원본: `rakkopng/*.png`
- 웹용 경량 버전: `rakkopng/web/*.webp` (게임에서 사용)
- 드라이브 차: `rakkopng/car.png` (누끼 원본) / `rakkopng/web/car.webp`
- 옷 위치는 `script.js`의 `ANCHORS`(표정별 머리·눈 위치)와 각 옷의 `place` 값으로 조정해요.
- 표정은 상태·행동에 따라 자동으로 바뀝니다 (배고픔 → expact, 졸림 → yawn, 토벌 → resolution, 쓰다듬기 → nod 등)

## ☁️ 서버 저장 켜기 (Firebase, 무료)

1. https://console.firebase.google.com 에서 **프로젝트 추가** (이름 아무거나, 애널리틱스는 꺼도 됨)
2. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` 추천 / **프로덕션 모드**로 시작
3. Firestore의 **규칙** 탭에 이 폴더의 `firestore.rules` 내용을 통째로 붙여넣고 **게시**
4. 프로젝트 개요 옆 톱니바퀴 → **프로젝트 설정 → 일반 → 내 앱**에서 웹 앱(`</>`) 추가
   - 나오는 `firebaseConfig` 값들을 `firebase-config.js`의 따옴표 안에 복사
5. 깃허브에 푸시하면 끝. (로그인 화면 아래 문구가 "어느 기기에서든 같은 랏코"로 바뀌면 성공)

- 예전에 이 브라우저에만 저장된 랏코는, 같은 비밀번호로 로그인하면 자동으로 서버로 옮겨져요.
- 무료 한도(하루 쓰기 2만 회)를 아끼려고 행동이 있을 때만 모아서 저장해요.
